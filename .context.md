# Backlinq — MCP Backlink Intelligence Tool

## Project Mission

Build a production-grade MCP (Model Context Protocol) server that unbundles Ahrefs/SEMrush backlink data ($1,200–$17,500/year) into $0.10/query AI-agent-ready responses. Listed on the CTX Protocol marketplace. Funded via the CTX $10K developer grant (Tier S: $1,000).

## Stack

- **Runtime:** Node.js 20+ (or Bun)
- **Package Manager:** Bun
- **Language:** TypeScript (strict mode, no `any`)
- **MCP SDK:** `@modelcontextprotocol/sdk`
- **CTX SDK:** `@ctxprotocol/sdk`
- **Data Sources:** Open PageRank API, Moz API (free tier), Common Crawl Index API
- **Deployment:** Railway (or Render)
- **Env Management:** `dotenv`

## Tools Exposed (MCP)

| Tool Name               | Input                              | Output                                           |
| ----------------------- | ---------------------------------- | ------------------------------------------------ |
| `get_backlink_profile`  | `domain: string`                   | Top backlinks, DR score, referring domains count |
| `get_domain_authority`  | `domain: string`                   | DA/DR score, trend, trust metrics                |
| `get_referring_domains` | `domain: string, limit?: number`   | List of referring domains with authority         |
| `compare_domains`       | `domainA: string, domainB: string` | Side-by-side backlink comparison                 |

## Key Constraints

- Response time MUST be under 30 seconds per query
- No raw data dumps — always return curated, analyzed, actionable output
- All errors must be structured JSON, never raw exceptions
- TypeScript strict mode — no `any`, no implicit types
- Each tool must work independently — no inter-tool dependencies at runtime
